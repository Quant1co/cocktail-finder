# Mixly — Cocktail Finder на React

Учебный проект для лабораторной по дисциплине «Кросс-платформенная разработка». Приложение получает данные о коктейлях из публичного API **TheCocktailDB** и показывает карточки, состав и инструкцию приготовления.

## Запуск

Требуется Node.js и npm.

```bash
npm install
npm run dev
```

Vite напечатает локальный адрес приложения (обычно `http://localhost:5173`). Для проверки production-сборки:

```bash
npm run build
npm run preview
```

## Возможности

- Поиск коктейлей по названию через `search.php?s=`.
- Фильтрация коктейлей по ингредиенту через `filter.php?i=`; для быстрого примера на странице есть `vodka`, `gin`, `rum`, `tequila` и `lemon`.
- Случайный коктейль через `random.php` — загружается при старте и по кнопке.
- Карточка рецепта с изображением, категорией, типом напитка, бокалом, ингредиентами с мерами и инструкцией.
- Адаптивный интерфейс для узких и широких экранов.
- Состояния загрузки, пустого результата и ошибки API.

> TheCocktailDB хранит большинство названий и ингредиентов на английском. Для поиска используйте, например, `margarita` или `vodka`.

## Какие запросы делает приложение

Базовый адрес: `https://www.thecocktaildb.com/api/json/v1/1/` — публичный тестовый ключ `1`.

| Задача | Пример endpoint |
|---|---|
| Поиск по названию | `search.php?s=margarita` |
| Фильтр по ингредиенту | `filter.php?i=vodka` |
| Подробная карточка по ID | `lookup.php?i=11007` |
| Случайный коктейль | `random.php` |

`filter.php` возвращает краткие данные для списка, поэтому при открытии такой карточки приложение дополнительно запрашивает `lookup.php` по ID. Результаты `search.php` и `random.php` уже содержат подробности.

## Нормализация данных

В ответе API ингредиенты приходят в отдельных свойствах: `strIngredient1` … `strIngredient15`, а меры — в `strMeasure1` … `strMeasure15`. Функция `normalizeCocktail()` в `src/App.jsx` проходит по этим полям и собирает удобный массив:

```js
[
  { name: 'Tequila', measure: '2 oz' },
  { name: 'Lime', measure: '1 oz' }
]
```

Так UI может отобразить ингредиенты обычным списком, не зная о структуре из 30 разрозненных полей.

## Короткое объяснение для защиты

1. Пользователь выбирает режим и вводит запрос. Обработчик `handleSearch()` формирует endpoint и отправляет `fetch`.
2. JSON-ответ преобразуется функцией `normalizeCocktail()` в единый формат.
3. React сохраняет результаты в `useState` и перерисовывает список карточек.
4. По нажатию на карточку открывается модальное окно с рецептом. Если карточка пришла из фильтра, сначала выполняется запрос деталей по ID.
5. Кнопка случайного выбора обращается к `random.php` и подменяет подборку одним случайным коктейлем.

**Стек:** React, JavaScript, Vite, Fetch API, TheCocktailDB.
